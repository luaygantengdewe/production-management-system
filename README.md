# Production & Human Resource Management Information System

## Overview

This project is a web-based Production & Human Resource Management Information System developed for CV Moreflex Surabaya to improve operational efficiency.

---

## Features

- Production Management
- Inventory Management (FIFO)
- Human Resource Management
- Employee Scheduling
- Overtime Management
- Customer Management
- Dashboard Analytics
- Reports

---

## Technologies

- Laravel 10
- PHP
- MySQL
- JavaScript
- Bootstrap
